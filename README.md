# Cap sur Bayonne

Application web autonome, sans dépendance ni compilation.

## Tester localement

Ouvrir `index.html` dans un navigateur.

## Mettre en ligne gratuitement avec Netlify Drop

1. Décompresser le ZIP.
2. Aller sur https://app.netlify.com/drop
3. Glisser-déposer le dossier `cap-sur-bayonne-clean` dans la page.
4. Netlify fournit une adresse web publique.

## Données

Les données sont enregistrées localement dans le navigateur. Elles ne sont pas automatiquement synchronisées entre deux téléphones.
Pour transférer les données : Réglages > Exporter mes données, puis Réglages > Importer mes données sur l'autre appareil.
